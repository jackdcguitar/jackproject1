#### 2.1.2 Spring Security 6.2.0

**技術介紹**：Spring Security 是 Spring 生態的安全框架。

**使用位置**：
- 用戶認證（Authentication）
- 授權控制（Authorization）
- 密碼加密
- CSRF 防護

**主要功能**：

1. **JWT 認證**
   - 檔案位置：`backend/src/main/java/com/jackproject/mall/config/SecurityConfig.java`
   - 技術：JWT (JSON Web Token)
   - 流程：
     ```
     1. 用戶登入 → 驗證用戶名密碼
     2. 生成 JWT Token → 返回給前端
     3. 前端儲存 Token → localStorage
     4. 後續請求攜帶 Token → Authorization: Bearer {token}
     5. 後端驗證 Token → 解析用戶資訊
     ```

2. **密碼加密**
   - 算法：BCrypt
   - 檔案位置：用戶註冊和登入邏輯
   - 特點：
     - 單向加密（無法解密）
     - 加鹽（Salt）防止彩虹表攻擊
     - 計算成本可調整

3. **權限控制**
   - 方法：基於角色的訪問控制（RBAC）
   - 註解：`@PreAuthorize`, `@Secured`
   - 範例：
     ```java
     @PreAuthorize("hasRole('ADMIN')")
     public void deleteProduct(Long id) { }
     ```

**配置範例**：
```java
// 密碼加密器
@Bean
public PasswordEncoder passwordEncoder() {
    return new BCryptPasswordEncoder();
}
```

**優點**：
- ✅ 功能全面，涵蓋所有安全需求
- ✅ 與 Spring 生態完美整合
- ✅ 社群支援豐富

### 2.2 持久層技術

#### 2.2.1 MyBatis Plus 3.5.5

**技術介紹**：MyBatis Plus 是 MyBatis 的增強工具。

**使用位置**：
- 資料訪問層（DAO）
- CRUD 操作
- 分頁查詢
- 條件構造器

**主要功能**：

1. **CRUD 介面**
   - 檔案位置：`backend/src/main/java/com/jackproject/mall/mapper/`
   - 範例：
     ```java
     public interface UserMapper extends BaseMapper<User> {
         // 無需編寫 SQL，自動實現 CRUD
     }
     ```

2. **條件構造器（Wrapper）**
   - 作用：動態構建 SQL 查詢條件
   - 範例：
     ```java
     QueryWrapper<Product> wrapper = new QueryWrapper<>();
     wrapper.eq("category_id", categoryId)
            .ge("price", minPrice)
            .le("price", maxPrice)
            .orderByDesc("sales");
     ```

3. **分頁插件**
   - 檔案位置：配置類
   - 使用：
     ```java
     Page<Product> page = new Page<>(current, size);
     productMapper.selectPage(page, wrapper);
     ```

4. **邏輯刪除**
   - 配置：實體類使用 `@TableLogic` 註解
   - 作用：刪除資料時不真正刪除，而是標記為已刪除
   - 優點：資料可恢復、便於審計

**配置檔案**：
```yaml
# application.yml
mybatis-plus:
  global-config:
    db-config:
      id-type: auto
      logic-delete-field: deleted
      logic-delete-value: 1
      logic-not-delete-value: 0
```

**優點**：
- ✅ 減少 SQL 編寫，提高開發效率
- ✅ 強大的條件構造器
- ✅ 內建分頁插件

### 2.3 快取技術

#### 2.3.1 Redis 7.0

**技術介紹**：開源的記憶體資料結構儲存系統。

**使用位置**：

1. **Session 管理**
   - 用途：儲存用戶登入狀態
   - Key 格式：`session:{userId}`
   - 過期時間：7 天

2. **資料快取**
   - 用途：快取熱門資料，減少資料庫查詢
   - 範例：商品詳情、分類列表
   - Key 格式：`product:{id}`, `category:list`
   - 過期時間：1 小時

3. **購物車**
   - 用途：儲存用戶購物車資料
   - 資料結構：Hash
   - Key 格式：`cart:{userId}`
   - 欄位：`{productId}:{quantity}`

4. **計數器**
   - 用途：商品瀏覽次數統計
   - 資料結構：String
   - 技術：INCR 命令（原子性操作）

**Spring 整合**：
```java
@Cacheable(value = "product", key = "#id")
public Product getProductById(Long id) {
    // 先查 Redis，沒有再查資料庫
    return productMapper.selectById(id);
}
```

**優點**：
- ✅ 極高效能（記憶體操作）

### 3.3 狀態管理

#### 3.3.1 Pinia 2.1.7

**技術介紹**：Vue 3 官方推薦的狀態管理庫。

**使用位置**：
- 全域狀態管理
- 用戶資訊、購物車等

**主要功能**：

1. **Store 定義**
   - 檔案位置：`frontend/src/stores/`
   - 語法：Setup Store（類似 Composition API）

2. **State（狀態）**
   - 定義：使用 `ref()` 或 `reactive()`
   - 範例：`const token = ref('')`

3. **Getters（計算屬性）**
   - 定義：使用 `computed()`
   - 範例：`const isLogin = computed(() => !!token.value)`

4. **Actions（方法）**
   - 定義：普通函數
   - 支援非同步
   - 範例：`async function login() { }`

5. **持久化**
   - 技術：localStorage
   - 實現：手動儲存和讀取

**範例**：
```javascript
// stores/user.js
export const useUserStore = defineStore('user', () => {
  // State
  const token = ref(localStorage.getItem('token') || '')

  // Getter
  const isLogin = computed(() => !!token.value)

  // Action
  async function login(username, password) {
    const res = await loginApi({ username, password })
    token.value = res.data
    localStorage.setItem('token', res.data)
  }

  return { token, isLogin, login }
})
```

**優點**：
- ✅ 比 Vuex 更簡單
- ✅ 完整的 TypeScript 支援
- ✅ 模組化設計
- ✅ DevTools 支援

### 4.1 關係型資料庫

#### 4.1.1 MySQL 8.0

**技術介紹**：世界最流行的開源關係型資料庫。

**使用位置**：
- 持久化資料儲存

- 複雜查詢

**資料表設計**：

- 文本：VARCHAR、TEXT

**字元集**：

**SQL 腳本**：
- 檔案位置：`database/schema.sql`（表結構）

**優化**：
1. **索引優化**
