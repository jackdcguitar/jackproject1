## 2. 本地開發部署

### 2.1 克隆專案

```bash
# 克隆專案到本地
git clone https://github.com/jackdcguitar/jackproject1.git

# 進入專案目錄
cd jackproject1
```

### 2.2 資料庫準備

#### Step 1：啟動 MySQL

```bash
# 方式一：使用系統服務
# macOS
brew services start mysql

# Linux (Ubuntu/Debian)
sudo systemctl start mysql

# Windows
net start MySQL80

# 方式二：使用 Docker
docker run -d \
  --name mysql \
  -p 3306:3306 \
  -e MYSQL_ROOT_PASSWORD=123456 \
  -e MYSQL_DATABASE=mall_db \
  -e TZ=Asia/Taipei \
  mysql:8.0
```

#### Step 2：建立資料庫

```bash
# 登入 MySQL
mysql -u root -p
# 輸入密碼：123456（或您設定的密碼）

# 建立資料庫
CREATE DATABASE mall_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# 退出
EXIT;
```

#### Step 3：執行 SQL 腳本

```bash
# 方式一：命令列執行
mysql -u root -p mall_db < database/schema.sql
mysql -u root -p mall_db < database/init-data.sql

# 方式二：使用 Navicat 等工具
# 1. 連接到 MySQL
# 2. 開啟 schema.sql 檔案並執行
# 3. 開啟 init-data.sql 檔案並執行
```

#### 驗證資料庫

```sql
-- 登入 MySQL
mysql -u root -p mall_db

-- 查看所有資料表
SHOW TABLES;

-- 應該看到：
-- t_user
-- t_product
-- t_category
-- t_cart
-- t_order
-- t_order_item
-- t_address
-- t_comment

-- 查看用戶資料
SELECT * FROM t_user;

-- 應該看到 3 個測試用戶
```

### 2.4 後端部署

#### Step 1：配置後端

```bash
cd backend
```

編輯配置檔案 `src/main/resources/application-dev.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/mall_db?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=Asia/Taipei
    username: root
    password: 123456  # 修改為您的 MySQL 密碼

  data:
    redis:
      host: localhost
      port: 6379
      password:  # 如果 Redis 有密碼，填寫在這裡
```

#### Step 2：安裝依賴

```bash
# 下載 Maven 依賴
mvn clean install -DskipTests

# 或者使用 IDEA
# 1. 開啟 pom.xml
# 2. 右鍵 -> Maven -> Reload Project
```

#### Step 3：啟動後端

```bash
# 方式一：使用 Maven
mvn spring-boot:run

# 方式二：使用 IDEA
# 1. 找到 MallApplication.java
# 2. 右鍵 -> Run 'MallApplication'

# 方式三：打包後運行
mvn clean package -DskipTests
java -jar target/*.jar
```

#### 驗證後端

```bash
# 檢查後端是否啟動成功
curl http://localhost:8080/api/actuator/health

# 應該返回：
# {"status":"UP"}

# 訪問 API 文檔
# 開啟瀏覽器訪問：http://localhost:8080/api/doc.html
```

## 3. Docker 容器化部署

### 3.1 快速啟動（推薦）

```bash
# 進入專案根目錄
cd jackproject1

# 一鍵啟動所有服務
docker-compose -f docker/docker-compose.yml up -d

# 查看服務狀態
docker-compose -f docker/docker-compose.yml ps

# 應該看到 4 個服務都在運行：
# - mall-mysql
# - mall-redis
# - mall-backend
# - mall-frontend
```

### 3.2 查看日誌

```bash
# 查看所有服務日誌
docker-compose -f docker/docker-compose.yml logs -f

# 只查看後端日誌
docker-compose -f docker/docker-compose.yml logs -f backend

# 只查看前端日誌
docker-compose -f docker/docker-compose.yml logs -f frontend
```

### 3.3 訪問服務

| 服務 | 地址 | 說明 |
|------|------|------|
| 前端 | http://localhost | 商城前台 |
| 後端 API | http://localhost:8080/api | RESTful API |
| API 文檔 | http://localhost:8080/api/doc.html | Knife4j 文檔 |
| MySQL | localhost:3306 | 資料庫（需客戶端連接） |
| Redis | localhost:6379 | 快取（需客戶端連接） |

### 3.4 停止服務

```bash
# 停止所有服務
docker-compose -f docker/docker-compose.yml down

# 停止並刪除資料卷（會刪除所有資料！）
docker-compose -f docker/docker-compose.yml down -v
```

### 3.5 重新構建

```bash
# 重新構建並啟動
docker-compose -f docker/docker-compose.yml up -d --build

# 只重新構建後端
docker-compose -f docker/docker-compose.yml build backend
docker-compose -f docker/docker-compose.yml up -d backend

# 只重新構建前端
docker-compose -f docker/docker-compose.yml build frontend
docker-compose -f docker/docker-compose.yml up -d frontend
```

## 4. 生產環境部署

### 4.1 伺服器準備

#### 系統要求

- **作業系統**：Ubuntu 20.04+ / CentOS 8+ / Debian 11+
- **CPU**：2 核心以上
- **記憶體**：4GB 以上（推薦 8GB）
- **硬碟**：20GB 以上

#### 安裝 Docker

```bash
# Ubuntu/Debian
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# 啟動 Docker
sudo systemctl start docker
sudo systemctl enable docker

# 安裝 Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/download/v2.20.0/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose
```

---

### 4.2 上傳專案

```bash
# 方式一：使用 Git（推薦）
ssh user@your-server-ip
git clone https://github.com/jackdcguitar/jackproject1.git
cd jackproject1

# 方式二：使用 SCP
# 在本地執行
scp -r jackproject1 user@your-server-ip:~/
```

---

### 4.3 配置生產環境

#### 修改後端配置

編輯 `backend/src/main/resources/application-prod.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://mysql:3306/mall_db?useUnicode=true&characterEncoding=utf-8&useSSL=true&serverTimezone=Asia/Taipei
    username: mall_user
    password: ${DB_PASSWORD}  # 使用環境變數

  data:
    redis:
      host: redis
      port: 6379
      password: ${REDIS_PASSWORD}

jwt:
  secret: ${JWT_SECRET}  # 使用強密碼

aliyun:
  oss:
    access-key-id: ${OSS_ACCESS_KEY_ID}
    access-key-secret: ${OSS_ACCESS_KEY_SECRET}
```

#### 設定環境變數

建立 `.env` 檔案：

```bash
# 檔案位置：docker/.env
DB_PASSWORD=your_strong_password_here
REDIS_PASSWORD=your_redis_password_here
JWT_SECRET=your_jwt_secret_key_at_least_256_bits
OSS_ACCESS_KEY_ID=your_oss_key_id
OSS_ACCESS_KEY_SECRET=your_oss_key_secret
```

### 4.5 設定 Nginx（可選）

如果需要配置域名和 HTTPS：

```nginx
# 檔案位置：/etc/nginx/sites-available/mall

server {
    listen 80;
    server_name your-domain.com;

    # 重定向到 HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name your-domain.com;

    # SSL 證書
    ssl_certificate /path/to/your/cert.pem;
    ssl_certificate_key /path/to/your/key.pem;

    # 前端
    location / {
        proxy_pass http://localhost:80;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # 後端 API
    location /api/ {
        proxy_pass http://localhost:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

啟用配置：

```bash
# 建立軟連接
sudo ln -s /etc/nginx/sites-available/mall /etc/nginx/sites-enabled/

# 測試配置
sudo nginx -t

# 重新載入 Nginx
sudo systemctl reload nginx
```

## 5. 常見問題

### 5.1 後端問題

#### 問題：後端啟動失敗

**錯誤訊息**：`Communications link failure`

**原因**：無法連接到 MySQL

**解決方案**：
1. 檢查 MySQL 是否啟動：`docker ps | grep mysql`
2. 檢查資料庫配置：`application.yml` 中的 URL、用戶名、密碼
3. 測試連接：`mysql -h localhost -u root -p`

---

#### 問題：Redis 連接失敗

**錯誤訊息**：`Unable to connect to Redis`

**原因**：Redis 未啟動或配置錯誤

**解決方案**：
1. 檢查 Redis 是否啟動：`docker ps | grep redis`
2. 測試連接：`redis-cli ping`
3. 檢查防火牆：`sudo ufw allow 6379`

---

#### 問題：埠被佔用

**錯誤訊息**：`Address already in use`

**解決方案**：
```bash
# 查看佔用 8080 埠的進程
lsof -i :8080

# 殺死進程
kill -9 <PID>

# 或者修改埠
# 編輯 application.yml，修改 server.port
```

---

### 5.2 前端問題

#### 問題：npm install 失敗

**解決方案**：
```bash
# 清除快取
npm cache clean --force

# 刪除 node_modules
rm -rf node_modules package-lock.json

# 重新安裝
npm install

# 或使用淘寶鏡像
npm config set registry https://registry.npmmirror.com
npm install
```

---

#### 問題：API 跨域錯誤

**錯誤訊息**：`CORS policy: No 'Access-Control-Allow-Origin' header`

**解決方案**：
1. 檢查 Vite 代理配置：`vite.config.js`
2. 確保後端已配置 CORS：Spring 配置類
3. 檢查請求 URL 是否正確

---

### 5.3 Docker 問題

#### 問題：容器無法啟動

**解決方案**：
```bash
# 查看詳細日誌
docker-compose logs backend

# 進入容器檢查
docker exec -it mall-backend sh

# 檢查健康狀態
docker inspect mall-backend | grep Health
```

---

#### 問題：資料卷權限問題

**錯誤訊息**：`Permission denied`

**解決方案**：
```bash
# 修改資料卷權限
docker exec -it mall-mysql chown -R mysql:mysql /var/lib/mysql

# 或者重新建立資料卷
docker-compose down -v
docker-compose up -d
```

### 5.4 效能優化

#### 資料庫優化

1. **建立索引**
   ```sql
   -- 為常用查詢欄位建立索引
   CREATE INDEX idx_product_category ON t_product(category_id);
   CREATE INDEX idx_order_user ON t_order(user_id);
   ```

2. **查詢優化**
   - 避免 SELECT *
   - 使用 LIMIT 限制結果數量
   - 避免 N+1 查詢問題

#### Redis 優化

1. **設定過期時間**
   ```java
   @Cacheable(value = "product", key = "#id", expire = 3600)
   ```

2. **使用合適的資料結構**
   - String：簡單鍵值
   - Hash：用戶資訊、購物車
   - List：訊息佇列
   - Set：標籤、去重

#### 應用優化

1. **啟用 Gzip 壓縮**（Nginx 已配置）
2. **使用 CDN**（圖片、CSS、JS）
3. **資料庫連接池**（Druid 已配置）
4. **分頁查詢**（MyBatis Plus 已支援）
